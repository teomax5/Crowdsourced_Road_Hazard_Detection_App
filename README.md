📌 AI Road Hazard Detection App

An intelligent mobile application that uses YOLOv8 (Computer Vision) + Flutter to detect and report road hazards in real time.

🚀 Project Overview

This project aims to improve road safety by enabling users to:

📸 Capture road images

🤖 Automatically detect hazards using AI

📍 Attach real-time GPS location

📝 Submit hazard reports

💾 Store reports locally

🧠 Key Features


🔹 AI-Based Hazard Detection

Uses YOLOv8 model for object detection

Detects:

Potholes

Waterlogging

Open manholes

🔹 Automatic Detection (Smart UX)

Detection runs immediately after image capture

No manual trigger required (like Google Lens)

🔹 Location Tracking

Captures:

Latitude

Longitude

🔹 Annotated Image Output

Displays bounding boxes around detected hazards

🛠️ Tech Stack

📱 Frontend

Flutter (Dart)

🧠 Backend

FastAPI (Python)
